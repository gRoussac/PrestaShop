# Gregoshop

Personal fork of [PrestaShop/PrestaShop](https://github.com/PrestaShop/PrestaShop).

PrestaShop is a very extensible e-commerce platform, both through modules and themes. Developers can even override the default components and behaviors. That is what this fork is for.

## Requirements

Same baseline as upstream PrestaShop 9:

- PHP 8.1+
- MySQL 5.6+ (or MariaDB / Percona equivalent)
- Apache or Nginx
