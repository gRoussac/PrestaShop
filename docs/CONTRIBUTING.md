# Contributing (this personal fork)

This repository is a **personal fork** of [PrestaShop/PrestaShop](https://github.com/PrestaShop/PrestaShop). It exists to customize and override default PrestaShop components and behaviors while tracking upstream `9.2.x` on branch `dev`.

It is not the place for general PrestaShop community contributions.

## Work on this fork

1. Branch from `dev` (`feat/…`, `fix/…`, `docs/…`, `chore/…`).
2. Open a pull request into `dev` on [gRoussac/PrestaShop](https://github.com/gRoussac/PrestaShop).
3. Prefer modules, themes, and `override/` when they are enough. Touch core only when the change belongs in this fork.

## Upstream PrestaShop

To contribute to official PrestaShop:

- Repository: [PrestaShop/PrestaShop](https://github.com/PrestaShop/PrestaShop)
- Guide: [project contributing docs](https://devdocs.prestashop-project.org/9/contribute/)
- Get involved: [prestashop-project.org/get-involved](https://www.prestashop-project.org/get-involved/)
